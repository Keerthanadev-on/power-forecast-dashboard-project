## 🚀 Overview

A data analytics and forecasting dashboard that predicts future power consumption using historical electricity usage data.

The project combines **data analysis**, **visualization**, and **time-series forecasting** to help understand energy demand trends and generate future consumption predictions.

---

## ✨ Features

✅ Interactive Dashboard

✅ State-wise Power Analysis

✅ Historical Trend Visualization

✅ SARIMA Forecasting Model

✅ Future Power Consumption Prediction

✅ Data Cleaning & Processing

## 📈 Forecasting Model

The project utilizes the **SARIMA (Seasonal AutoRegressive Integrated Moving Average)** model to capture seasonal energy consumption patterns and generate accurate future forecasts.
